## 发现并修复

| 问题 | 修复后的行为 |
| --- | --- |
| `--root` 可把普通目录当作库；工作区可借用非资产主库 | 验证当前库和主库的格式标记后再加载操作，不创建错误位置的本机状态 |
| 包目录、共享记忆或本机候选路径经链接越界 | 读写和候选移动前检查路径的每一层，保留库外内容 |
| 接受候选时可覆盖尚未登记修订的资产库编辑 | 更换包前复核当前文件与已审 manifest，双方变化先审阅、合并 |
| 普通部署未重新扫描实际安装版本 | 在切换任何目标之前扫描准备好的确切版本，失败清理自有暂存目录 |
| 原生上层目录链接变化未使预览失效 | 冻结计划同时记录逻辑路径和解析后的实际目标地址，并在准备完成后复核；按实际位置清理自有暂存包 |
| preparing、rolling_back 试用可能被普通部署接管 | 持续保留目标所有权，其他试用不能占用，审计要求恢复 |
| 暂存扫描期间新增文件可能被遗漏后仍提交、合并 | 复核全部包和未跟踪文件，在提交前停止并保留索引与现场 |
| 仅验证主库 origin，遗漏工作区远端覆写 | 查询 GitHub 状态前验证两处实际 fetch/push URL |
| 环境文件与数据库扩展名拦截不完整 | 拦截实际环境配置、私钥容器及 SQLite/DB 日志侧车；示例仍需内容扫描 |
| 本机 instance 可混入共享绑定，类型和名称冲突可污染登记 | 绑定仅接受 agent/path；校验类型、路径、文件模式及唯一名称，重复目标去重 |
| 手动登记、修订缺少入口字段检查 | 在更改登记内容前检查 Skill 入口字段 |
| 示例未切入资产库、合并后沿用旧候选 ID，适配器说明缺失 | 修正命令顺序和返回 ID，补充适配与自定义探针信任范围 |
| 源码发行包遗漏文档、schema 和验证入口 | 明确包含公开文件，排除本机配置、工件、环境及构建目录 |

## 资产与隐私边界

未在源码、跟踪文档、空白模板中发现原用户的姓名、账号标识、业务环境或本机绝对路径。安装包继续只提供空白框架；合成 Skill 只用于测试。私有资产库可保存经审阅的领域环境背景；客户端安装路径、实例别名、连接映射、候选和运行状态留在本机。

显式 local-source 的来源会记录本地 Git URL，接受前需决定能否共享；工具不自动脱敏。内容的事实性与归属依赖审阅，秘密扫描和格式检查不能替代授权判断。既有本地 Git 历史未改写。
